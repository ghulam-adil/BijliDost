# Bijli Dost Urdu Fonts

Place the official Google Noto font binary `.ttf` files in this directory:
1. `NotoNastaliqUrdu-Regular.ttf` (from Google Fonts: https://fonts.google.com/noto/specimen/Noto+Nastaliq+Urdu)
2. `NotoSansArabic-Regular.ttf` (from Google Fonts: https://fonts.google.com/noto/specimen/Noto+Sans+Arabic)

These provide high-legibility Nastaliq typography for long explanations and crisp Arabic/Urdu sans-serif typography for compact buttons, lists, and navigation tabs.
